# Localization and Mapping System for Autonomous Inspection Robots

Cartographer is a real-time simultaneous localization and mapping (SLAM) system for mobile robots. OpenSentinel is an advanced autonomous UAV control system featuring real-time Edge-AI visual tracking. Environment Simulator Minimalistic (esmini) is a basic OpenSCENARIO XML player. map_manager is a library implementing various 3D mapping algorithms, such as occupancy voxel map, ESDF Map, dynamic map for autonomous mobile robots. Deepdrive is a simulator that allows anyone with a PC to push the state-of-the-art in self-driving. Andino is a fully open-source diff drive robot designed for educational purposes and low-cost applications. AutoDRIVE is envisioned to be an integrated platform for autonomous driving research and education. The JPL Open Source Rover is an open source, build it yourself, scaled down version of the 6 wheel rover design that JPL uses to explore the surface of Mars. 3D Mapping System is an open-source project providing 3D-printable modular parts, sensor initialization scripts, and SLAM system integration for creating versatile 3D mapping solutions for both robots and handheld devices. ConceptFusion is a framework designed for open-set multimodal 3D mapping, enabling the integration of diverse data modalities into a unified 3D representation. Nav2 is the go-to industry-standard mobile robot navigation system, deploying Autonomous Vehicle technologies brought down, reworked, and optimized for mobile and surface robotics. GLIM is a versatile and extensible range-based 3D mapping framework. OctoMap is an efficient probabilistic 3D mapping framework based on octrees. ROS Based 3D Mapping Rover with User Interface. Multi-Sensor 3D mapping with an unmanned ground vehicle for mining applications. Laser_RobMap is a ROS2 package designed for three-dimensional mapping using a two-dimensional LiDAR sensor mounted on a mobile robotic platform

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
