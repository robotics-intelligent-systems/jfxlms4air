# Localization and Mapping System for Autonomous Inspection Robots

ORB-SLAM3 is the first real-time SLAM library able to perform Visual, Visual-Inertial and Multi-Map SLAM. OKVIS is an open keyframe-based visual-inertial SLAM. VINS-Mono is a real-time SLAM framework for Monocular Visual-Inertial Systems. Swarm-SLAM is an open-source C-SLAM system. AG-LOAM is a light-weight LiDAR-only odometry and mapping framework. FAST-LIO is a computationally efficient and robust LiDAR-inertial odometry package. LidarView performs real-time reception, recording, visualization and processing of 3D LiDAR data. FOS_UAV is an open source aerial mapping platform. Cartographer is a real-time simultaneous localization and mapping system. OpenSentinel is an advanced autonomous UAV control system. map_manager is a library implementing various 3D mapping algorithms. VILA is an Optimized Vision Language Models. ReMEmbR is a project that uses LLMs + VLMs to build and reason over long horizon spatio-temporal memories. 3D Mapping System is an open-source project providing 3D-printable modular parts, sensor initialization scripts, and SLAM system integration for creating versatile 3D mapping solutions for both robots and handheld devices. ConceptFusion is a framework designed for open-set multimodal 3D mapping, enabling the integration of diverse data modalities into a unified 3D representation. Nav2 is the go-to industry-standard mobile robot navigation system, deploying Autonomous Vehicle technologies brought down, reworked, and optimized for mobile and surface robotics. GLIM is a versatile and extensible range-based 3D mapping framework. OctoMap is an efficient probabilistic 3D mapping framework based on octrees. ROS Based 3D Mapping Rover with User Interface. Multi-Sensor 3D mapping with an unmanned ground vehicle for mining applications. Laser_RobMap is a ROS2 package designed for three-dimensional mapping using a two-dimensional LiDAR sensor mounted on a mobile robotic platform

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
